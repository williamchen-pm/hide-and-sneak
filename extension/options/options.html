Hide & Sneak

Let browser AI agents see only what they need. Everything here stays on this computer.

How to use it

  1. Click the Hide & Sneak icon in the Chrome toolbar. (If you don't see it, click the puzzle-piece icon and pin Hide & Sneak.)
  2. Turn on Agent Mode before you hand a task to your AI agent.
  3. Sensitive text shows as placeholders like [CARD #]. Sensitive form fields show 🔒 You fill this one. Your agent sees exactly what you see.
  4. When the agent is done, turn Agent Mode off. Locked fields unlock right away so you can fill them in. Reload a page to see hidden text again.

Protected pages

One URL pattern per line. Use * as a wildcard. While Agent Mode is on, matching pages are replaced with a "This page is protected" notice.
Examples: https://www.amazon.com/cpe/yourpayments/*   *://*.mybank.com/statements*

Protected words and phrases

One phrase per line. Matching text is replaced with [PROTECTED] on every page while Agent Mode is on. Example: a project name, a medication, a family member's name.
